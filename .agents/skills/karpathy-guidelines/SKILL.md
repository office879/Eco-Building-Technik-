# Coding-Gegenprüfung für Fernberg-Projekte

Adaption der vier Coding-Prinzipien aus dem öffentlich zugänglichen Repository multica-ai/andrej-karpathy-skills; keine offizielle persönliche Veröffentlichung von Andrej Karpathy.

1. **Vorher verstehen:** Aufgabe, existierenden Code und Abhängigkeiten prüfen. Wesentliche Annahmen und Mehrdeutigkeiten nennen. Bei entscheidenden Lücken nicht raten.
2. **Einfach bleiben:** Nur erforderliche Funktion bauen. Keine zusätzliche Architektur, vorauseilende Optionen oder unnötigen Wrapper.
3. **Gezielt ändern:** Kleinstmöglichen Diff erstellen, vorhandene Schnittstellen und fremde Änderungen bewahren. Keine unbestellten Umstrukturierungen.
4. **Ergebnisse nachweisen:** Reproduzierbare Erfolgskriterien und relevante Tests vorsehen. Bei Fehlerbehebung Fehler zuerst möglichst reproduzieren. Nach Änderungen Tests ausführen, Diff kontrollieren und verbleibende Risiken dokumentieren.

Die Projektregeln aus AGENTS.md gelten zusätzlich. Insbesondere keine externen rechtswirksamen Schritte, Zahlungsfreigaben, Veröffentlichung, Geheimnisoffenlegung oder Löschung allein wegen einer Programmieranforderung.
